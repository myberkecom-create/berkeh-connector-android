# برکه کانکتور ۱.۰.۰

اپ اندروید برای افزونه `berkeh-smart-c2c-unified` نسخه ۲.۰.۰. Android 8 به بالا؛ شناسه `com.berkeh.connector`.

## نصب و اتصال
1. APK را روی گوشی‌ای نصب کنید که پیامک واریز حساب فروشگاه را دریافت می‌کند. در صورت درخواست گوشی، نصب از منبع مورد استفاده خود را اجازه دهید.
2. در پیشخوان وردپرس، کارت‌به‌کارت ← تنظیمات ← API موبایل، کلید مشترک را کپی کنید. در تب «اتصال» اپ، آدرس نهایی HTTPS سایت و کلید را وارد و ذخیره کنید. اگر وردپرس داخل پوشه است آن پوشه را هم در آدرس بگذارید. `/wp-json` را وارد نکنید.
3. نام یا شماره دقیق فرستنده پیامک واقعی بانک را در «فرستنده‌های مجاز» وارد کنید؛ هر فرستنده در یک خط. تطبیق کامل و بدون حساسیت به بزرگی حروف انگلیسی است. فیلتر خالی یعنی هیچ پیامکی ارسال نمی‌شود. نام بانک به‌تنهایی کافی نیست، مگر فرستنده واقعاً همان نام باشد. برای ایران‌زمین و بانک‌های دیگر، فرستنده واقعی را وارد کنید؛ تشخیص قالب پیامک توسط افزونه سایت انجام می‌شود.
4. «آزمایش اتصال» را بزنید. سپس از خانه، ارسال خودکار را فعال و مجوز دریافت پیامک را تأیید کنید.
5. در تنظیمات گوشی، مصرف باتری اپ را نامحدود و فعالیت پس‌زمینه/Auto-start را در صورت وجود فعال کنید. Force stop باعث توقف دریافت تا بازکردن مجدد اپ می‌شود.

## آزمایش واقعی قبل از استفاده عملیاتی
- ابتدا متن یک پیامک واقعی را در «تستر و عیب‌یابی» افزونه بررسی کنید؛ واحد ریال/تومان، حساب مقصد، نوع واریز و مبلغ باید درست تشخیص داده شوند.
- یک سفارش آزمایشی در سایت بسازید و واریز واقعی کم‌مبلغ با مبلغ دقیق نمایش‌داده‌شده انجام دهید.
- در گزارش اپ، ثبت در سایت را بررسی کنید؛ سپس در تراکنش‌های افزونه، مبلغ، parser_status، match_status و سفارش متصل را کنترل کنید.
- «ارسال شد» در اپ به معنی پرداخت‌شدن سفارش نیست. تطبیق و تأیید توسط تنظیمات افزونه انجام می‌شود. اپ هیچ مبلغ، شماره کارت یا نتیجه تأیید ساختگی به API تحمیل نمی‌کند.
- قطع اینترنت و وصل مجدد را هم آزمایش کنید. صف باید ارسال شود و یک پیامک تکراری نباید تراکنش دیگری بسازد.

## امکانات و محدودیت‌ها
- رابط فارسی، گزارش ۳۰ پیامک اخیر و شمارنده‌های صف/ارسال/خطا.
- امضای HMAC-SHA256(timestamp + newline + raw JSON)، شناسه پایدار پیام، nonce تصادفی، HTTPS بدون دنبال‌کردن redirect.
- صف SQLite با رمزگذاری AES-GCM مبتنی بر Android Keystore. کلید API نیز رمزگذاری می‌شود. بعد از ارسال موفق، متن محلی پاک می‌شود. گزارش‌های موفق قدیمی‌تر از ۳۰ روز در همگام‌سازی بعدی پاک می‌شوند.
- ارسال پس‌زمینه با JobScheduler؛ تلاش مجدد هنگام شبکه و بررسی دوره‌ای تقریباً هر ۱۵ دقیقه. زمان دقیق به اندروید و سازنده گوشی بستگی دارد؛ ارسال فوری تضمین نمی‌شود. دکمه «ارسال صف اکنون» برای ارسال از اپ باز در دسترس است.
- پیامک چندبخشی در یک پیام جمع می‌شود. فقط پیامک‌های جدید پس از فعال‌سازی دریافت می‌شوند؛ مجوز READ_SMS، مخاطبین یا Accessibility درخواست نشده است.
- پیامک‌های حاوی «رمز»، «کد ورود»، OTP، password یا verification code ارسال نمی‌شوند؛ اگر بانک این عبارت‌ها را در متن تراکنش هم استفاده کند ممکن است آن پیامک فیلتر شود.
- دکمه پنل سفارش‌ها، وب‌اپ موجود سایت در مسیر /c2c-app/ را در مرورگر باز می‌کند. ورود با کاربر ساخته‌شده در بخش «کاربران وب‌اپ» افزونه است، نه کلید API.
- هر نصب یک سایت فعال دارد؛ اپ برای سایت‌های مختلف قابل تنظیم است، اما همزمان به چند سایت ارسال نمی‌کند.

## خطاهای رایج
- 401/403: کلید، ساعت خودکار گوشی و محدودیت فایروال سایت را بررسی کنید.
- 404: افزونه فعال، آدرس صحیح و دسترسی REST API را بررسی کنید.
- تغییر مسیر: نسخه نهایی آدرس، مثلاً با www یا بدون آن، باید دقیق وارد شود.
- ignored/sender_filter: فیلتر فرستنده داخل خود افزونه سایت را بررسی کنید.
- parsed/unmatched یا needs_review: پیامک به سایت رسیده ولی افزونه سفارش را تطبیق نداده است؛ تستر افزونه را بررسی کنید.
- تغییر سایت با صف ارسال‌نشده مسدود است؛ ابتدا صف را ارسال یا آگاهانه حذف کنید. برای تغییر کلید یا فرستنده‌ها، ابتدا ارسال را متوقف کنید.
- توقف ارسال، درخواست شبکه‌ای را که از قبل شروع شده پس نمی‌گیرد.
- داده‌های صف خطادار تا حذف دستی باقی می‌مانند. پاک‌کردن داده اپ یا حذف اپ، صف و کلید ذخیره‌شده را از بین می‌برد.

## ساخت از سورس
JDK 17، Gradle 8.9، Android SDK 35 و Build Tools 35.0.0 لازم است. پروژه بدون وابستگی خارجی در زمان اجرا است.

```sh
gradle :app:assembleDebug
```

برای خروجی امضاشده با همان کلید APK تحویلی، فایل پشتیبان امضا را خصوصی استخراج کرده و متغیرها را تنظیم کنید:

```sh
export BERKEH_KEYSTORE=/absolute/private/path/berkeh-release.jks
export BERKEH_STORE_PASSWORD='password-from-private-backup'
gradle :app:assembleRelease
```

فایل release بدون تنظیم کلید امضا قابل نصب مستقیم نیست. APK تحویلی امضای release دارد. خروجی debug امضای دیگری دارد و روی نسخه release نصب نمی‌شود؛ برای به‌روزرسانی بدون حذف داده، همان کلید امضا و versionCode بالاتر لازم است.

Workflow آماده در `.github/workflows/android-build.yml` قرار دارد. بدون Secrets خروجی debug می‌سازد؛ با BERKEH_KEYSTORE_BASE64 (محتوای فایل jks به صورت base64) و BERKEH_STORE_PASSWORD خروجی release می‌سازد. فایل امضا و رمز آن را در مخزن عمومی قرار ندهید.

## محدوده بررسی این تحویل
سورس با Android SDK 35 کامپایل شده؛ منابع، DEX، ساختار APK و امضای دیجیتال بررسی شده‌اند. تست قرارداد امضا با محاسبه مستقل HMAC، URL، فرستنده دقیق و فیلتر OTP اجرا شده است. نصب روی گوشی واقعی، مجوزها، رفتار باتری سازنده گوشی و اتصال end-to-end به فروشگاه شما هنوز تست نشده‌اند. کد افزونه وردپرس تغییری نکرده و ممیزی کامل امنیتی آن جزو این تحویل نیست. ارسال پیامک این اپ جای اتصال مستقیم بانکی را نمی‌گیرد.
